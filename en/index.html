Is my file sent to a server?

No. There is no upload path; parsing and rendering stay in your browser. Once loaded, the viewer also works without a network connection. Anonymous page and feature-use statistics help improve MDVIEW; filenames and document content are never included.

Which Markdown features are supported?

MDVIEW supports tables and alignment, task lists, footnotes, collapsible blocks, frontmatter, and syntax highlighting. Long documents get an automatic contents rail.

Can I copy a document or save it as a PDF?

Copy preserves headings, lists, and table alignment when you paste into Word or Google Docs. Press Ctrl+P to print or save as PDF.

Can I open .md files by double-clicking them?

No installation is needed to use the web viewer. Optionally install MDVIEW in Chrome or Edge and use it as a .md file handler on Windows. View setup guide →
