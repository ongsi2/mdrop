# 내일 확인할 것

자동화로는 닿지 않는 것만 모았습니다. **A 가 가장 중요합니다** — 여기서 막히면
이 사이트의 존재 이유가 없어집니다.

> 이 파일 자체가 첫 테스트 문서입니다. 표·체크박스·코드·인용이 다 들어 있으니
> 이걸로 렌더링과 서식 복사를 같이 확인하시면 됩니다.

---

## A. 설치와 파일 연결 · 5분

가장 의심스러운 구간입니다.

- [ ] **A-1** Chrome 또는 Edge 로 `https://mdrop.app/install/` 접속
- [ ] **A-2** 상단에 `앱으로 설치` 버튼이 보이는가
  - 안 보이면 → 주소창 오른쪽 끝 설치 아이콘, 또는 `⋮ → 캐스트·저장·공유 → 페이지를 앱으로 설치`
  - **버튼이 안 보이는 건 정상일 수 있습니다.** 브라우저가 페이지마다 다르게 판단합니다
- [ ] **A-3** 설치 후 작업표시줄·시작 메뉴에 MDVIEW 아이콘이 생겼는가
- [ ] **A-4** `.md` 파일 우클릭 → 연결 프로그램 → **다른 앱 선택** → 목록에 **MDVIEW 가 뜨는가**
  - ⚠️ **여기가 제일 의심됩니다.** 안 뜨면 `내 PC 에서 앱 선택` 도 눌러보고, 그래도 없으면 알려주세요
- [ ] **A-5** `항상 이 앱을 사용` 체크 후 확인
- [ ] **A-6** 아무 `.md` 더블클릭 → 브라우저가 "MDVIEW 에서 .md 파일을 열도록 허용할까요?" 한 번 묻는가
- [ ] **A-7** 허용 후, **주소창·탭 없는 독립 창**에 렌더된 문서가 뜨는가
- [ ] **A-8** 다른 `.md` 를 또 더블클릭 → 이제 안 묻고 바로 열리는가

## B. 서식 복사 → 한글 · 워드 · 3분

- [ ] **B-1** 이 파일을 열고 상단 `서식 복사` 클릭 (또는 `C` 키)
- [ ] **B-2** **한글(HWP)** 에 붙여넣기
  - [ ] 표에 테두리가 있는가
  - [ ] 아래 표의 **금액 칸이 오른쪽 정렬**인가 ⚠️ 의심 구간
  - [ ] 제목이 큰 글씨로 구분되는가
  - [ ] `**굵게**` 같은 기호가 안 딸려왔는가
- [ ] **B-3** **워드** 에도 붙여넣기 (한글과 다르게 나올 수 있음)
- [ ] **B-4** **메모장** 에 붙여넣기 → 이건 반대로 **원본 마크다운**이 나와야 정상

| 항목 | 구분 | 금액 |
| --- | :-: | ---: |
| 홈페이지 제작 | A | 4,800,000 |
| 유지보수 12개월 | B | 1,200,000 |
| **합계** | | **6,000,000** |

## C. 폴더 드롭과 라이브 리로드 · 3분

- [ ] **C-1** 이미지가 들어간 md 가 있는 **폴더를 통째로** 창에 드롭
- [ ] **C-2** `![](./img/xxx.png)` 이미지가 실제로 보이는가 ⚠️ 자동화로 검증 못 한 구간
- [ ] **C-3** 우상단에 `LIVE` 뱃지가 켜졌는가
- [ ] **C-4** VS Code 로 그 파일 열어서 아무거나 고치고 **저장**
- [ ] **C-5** 저장하는 순간 화면이 다시 그려지는가 (1초 이내)
- [ ] **C-6** 문서 중간쯤 스크롤한 상태에서 **문서 위쪽**에 문단을 추가하고 저장
  - 읽고 있던 위치가 그대로 유지되는가

## D. 인쇄 · PDF · 2분

- [ ] **D-1** 문서 연 상태에서 `Ctrl` + `P`
- [ ] **D-2** 미리보기에서 상단바·목차가 사라지고 본문만 나오는가
- [ ] **D-3** 표와 코드 블록이 페이지 경계에서 **잘리지 않는가**
- [ ] **D-4** PDF 로 저장해서 열어보기

```ts
// 이 코드 블록이 인쇄 시 두 페이지로 쪼개지지 않아야 합니다
export const quote = {
  base: 4_800_000,
  maintenance: 1_200_000,
  total(): number {
    return this.base + this.maintenance;
  },
};
```

## E. 잡다한 것 · 2분

- [ ] **E-1** `D` 키로 라이트 모드 → 글자가 다 읽히는가
- [ ] **E-2** `T` 키로 목차 껐다 켜기
- [ ] **E-3** 코드 블록에 마우스 올리면 `복사` 버튼이 뜨는가
- [ ] **E-4** 휴대폰으로 `mdrop.app` 접속 → 좌우로 밀리지 않는가
- [ ] **E-5** 첫 화면에 `최근 문서` 칩이 생겼는가 (한 번 연 뒤)
- [ ] **E-6** 비행기 모드 켜고 앱 실행 → 열리는가
- [ ] **E-7** `/install/` 페이지에 md 를 드롭 → 홈으로 넘어와 렌더되는가 (오늘 추가된 기능)
- [ ] **E-8** 문서 열어둔 채 그 파일을 탐색기에서 **삭제** → LIVE 뱃지가 꺼지는가 (오늘 추가)
- [ ] **E-9** 문서 보다가 **뒤로가기** → 사이트 밖으로 나가지 않고 첫 화면으로 오는가 (오늘 수정)
- [ ] **E-10** 문서 보다가 `Esc` → 같은 동작 (첫 화면, 최근 문서 칩에 방금 본 파일 추가)
- [ ] **E-11** 설치를 마친 뒤 일반 탭으로 `/install/` 접속 → "이미 설치되어 있습니다" 가 뜨는가 (오늘 추가)

## 아직 안 고친 것 (알고 계시라고)

1. **커스텀 404 페이지가 안 붙습니다.** 404 상태코드는 정상이지만 Vercel 기본 화면이 나옵니다.
   세 가지 방법 다 실패했고, Vite 프리셋 쪽 문제로 보입니다. 기능엔 지장 없습니다.
2. **`/en/` 에서 앱을 설치해도 실행하면 한국어 화면이 뜹니다.** 매니페스트의 시작 주소가
   하나뿐이라 그렇습니다. 상단 언어 링크로 넘어가면 그 선택은 기억됩니다.
