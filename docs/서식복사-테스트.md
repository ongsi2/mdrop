# 서식 복사 검증 문서

이 문서를 열고 `서식 복사` → 한글·워드에 붙여넣은 뒤, 각 항목 옆의 **기대 결과**와
비교하면 됩니다. 스샷 한 장이면 어디가 깨지는지 다 보입니다.

## 1. 표 정렬 — 가장 중요

아래 표에서 **구분 열은 가운데, 금액·수량 열은 오른쪽**이어야 합니다.

| 항목 | 구분 | 수량 | 금액 |
| :-- | :-: | --: | --: |
| 홈페이지 제작 | 신규 | 1 | 4,800,000 |
| 반응형 추가 | 옵션 | 1 | 800,000 |
| 유지보수 | 월간 | 12 | 1,200,000 |
| **합계** | | | **6,800,000** |

기대: 테두리 있음 · 헤더 행 구분됨 · 합계 행 굵게 · 금액 오른쪽 정렬

## 2. 글자 서식

이 문단에는 **굵게**, *기울임*, ~~취소선~~, `인라인 코드`, [링크](https://mdrop.app)가
섞여 있습니다.

기대: 각 서식 유지 · `**` `~~` 같은 기호가 보이면 실패

## 3. 제목 크기

# 제목 1 (가장 큼)
## 제목 2
### 제목 3

기대: 세 단계 크기 차이가 보임


기대: 인용 구분됨 · 코드가 고정폭 글꼴
