SETUP GUIDE

.md 파일을 더블클릭해서
바로 여는 법

마크다운을 열 때마다 브라우저를 켜고 파일을 끌어다 놓는 게 번거롭다면, MDVIEW 를 앱으로 설치해 .md 파일의 기본 프로그램으로 지정할 수 있습니다. 내려받을 설치 파일은 없습니다 — 브라우저가 직접 등록합니다. 2분이면 끝납니다.

이 브라우저에서 바로 설치할 수 있습니다

이미 설치되어 있습니다

아래 3단계만 하시면 더블클릭으로 열립니다.

설치 버튼이 여기 안 보이나요?

브라우저는 아무 때나 설치 버튼을 내주지 않습니다. 주소창 오른쪽 끝의 설치 아이콘을 누르거나, 브라우저 메뉴 ⋮ → 캐스트·저장·공유 → 페이지를 앱으로 설치 로 바로 설치하실 수 있습니다. Firefox 와 Safari 에는 이 기능이 없습니다.

  1. 01

    Chrome 또는 Edge 로 엽니다

    파일 연결은 Chromium 계열 데스크톱 브라우저에만 있는 기능입니다. Firefox 와 Safari 에서는 이 단계부터 진행되지 않습니다. 다만 파일을 끌어다 놓아 읽는 것은 어느 브라우저에서나 됩니다.

  2. 02

    앱으로 설치합니다

    상단 앱으로 설치 버튼을 누릅니다. 버튼이 보이지 않으면 주소창 오른쪽 끝의 설치 아이콘을 누르거나, 브라우저 메뉴 ⋮ → 캐스트·저장·공유 → 페이지를 앱으로 설치 를 고르시면 됩니다.

    설치해도 내려받는 파일은 없습니다. 브라우저가 바로 등록하고, 작업표시줄과 시작 메뉴에 아이콘이 생깁니다.

  3. 03

    .md 의 연결 프로그램을 MDVIEW 로 바꿉니다

    여기가 유일하게 손이 가는 단계입니다. 탐색기에서 아무 .md 파일을 고르고:

    우클릭 → 연결 프로그램 → 다른 앱 선택 → MDVIEW → 항상 이 앱을 사용 체크

    Windows 11 에서는 연결 프로그램 → 다른 앱 선택 대신 연결 프로그램 → 다른 앱 선택 → 항상 순서로 나오기도 합니다. 목록에 MDVIEW 가 없다면 내 PC 에서 앱 선택 을 눌러 찾으시면 됩니다.

  4. 04

    첫 실행 때 권한을 허용합니다

    처음 여는 순간 브라우저가 “MDVIEW 에서 .md 파일을 열도록 허용할까요?” 를 한 번 묻습니다. 허용하면 그다음부터는 묻지 않습니다.

확인해보기

탐색기에서 아무 .md 파일을 더블클릭해 보세요. 브라우저 주소창도 탭도 없는 독립 창에 렌더된 문서가 뜨면 성공입니다.

지우고 싶으면

앱 창의 ⋮ → MDVIEW 제거, 또는 Windows 설정 → 앱 에서 제거하면 끝입니다. 일반 프로그램이 아니라 브라우저가 등록한 앱이라 언인스톨러도, 레지스트리 잔여물도 없습니다. 연결 프로그램은 다시 원하는 앱으로 지정하시면 됩니다.

macOS 와 Linux 에서도 되나요

됩니다. Chrome 이나 Edge 로 설치한 뒤 파일을 우클릭해 기본 앱을 MDVIEW 로 지정하는 방식은 같습니다. 메뉴 이름만 정보 가져오기 → 다음으로 열기 처럼 달라집니다.

회사 컴퓨터에서도 되나요

보통은 됩니다. 관리자 권한이 필요 없고 설치 파일을 받지도 않기 때문입니다. 다만 조직에서 정책으로 웹 앱 설치를 막아둔 경우에는 설치 버튼이 나타나지 않습니다. 그럴 때는 그냥 사이트에 파일을 끌어다 놓아 쓰시면 됩니다.

인터넷이 끊겨도 열리나요

열립니다. 설치하면 앱이 브라우저에 저장돼서 네트워크 없이도 동작합니다. 애초에 파일을 서버로 보내지 않기 때문에 인터넷이 필요한 부분이 없습니다.

설정이 끝나면 첫 화면은 이제 필요 없습니다. 파일을 더블클릭하시면 됩니다.
