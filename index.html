md 파일, 왜 열기가 이렇게 번거로울까요

마크다운은 그냥 텍스트 파일인데, 정작 읽으려면 전용 프로그램을 깔아야 합니다. 깔고 나면 라이선스를 묻거나, 계정을 만들라고 하거나, 켜지는 데만 몇 초가 걸립니다. 파일 하나 보자고 치르기엔 과한 비용입니다.

MDVIEW 는 그 단계를 전부 없앴습니다. 이 페이지에 .md 파일을 끌어다 놓으면 그 자리에서 렌더링됩니다. 회원가입도, 설치 파일도, 결제도 없습니다.

파일은 어디에도 올라가지 않습니다

이 사이트에는 업로드 기능이 존재하지 않습니다. 서버로 파일을 보내는 코드 자체가 없고, 파싱과 렌더링이 전부 브라우저 안에서 끝납니다. 계약서나 사내 문서처럼 밖으로 나가면 안 되는 파일도 안심하고 열 수 있습니다. 인터넷을 끊고도 동작합니다.

읽을 수 있는 것

GitHub 스타일 표와 정렬, 체크리스트, 각주, 접이식 블록, 프론트매터, 코드 하이라이트를 지원합니다. 한국어 조판을 따로 손봐서 단어 중간에서 줄이 끊기지 않습니다. 긴 문서에는 목차가 자동으로 생기고, 스크롤에 따라 현재 위치가 표시됩니다.

탐색기에서 .md 더블클릭으로 열기

Chrome 이나 Edge 에서 이 사이트를 앱으로 설치하면, Windows 가 MDVIEW 를 .md 파일의 연결 프로그램으로 인식합니다. 그다음부터는 탐색기에서 더블클릭 한 번이면 렌더된 화면이 뜹니다. 설치 파일을 내려받는 방식이 아니라 브라우저가 바로 등록해 주는 방식이라, 지우고 싶으면 앱 목록에서 제거하면 끝입니다.

고치면 바로 반영됩니다

파일을 열어둔 채로 편집기에서 저장하면, 화면이 알아서 다시 그려집니다. 스크롤 위치는 그대로 유지됩니다. 편집은 쓰던 도구에서 하고 결과만 여기서 보면 됩니다.

Q.01

md 파일은 무엇으로 여나요?

메모장으로 열면 # 이나 ** 같은 기호가 그대로 보입니다. 보기 좋게 읽으려면 마크다운 뷰어가 필요한데, 보통은 프로그램을 설치해야 합니다. 이 페이지에 파일을 끌어다 놓으면 설치 없이 바로 읽힙니다.

Q.02

프로그램 설치 없이 마크다운을 볼 수 있나요?

네. 브라우저만 있으면 됩니다. 회원가입도 로그인도 없고, 파일을 창에 끌어다 놓는 즉시 렌더링됩니다.

Q.03

파일이 서버에 올라가나요?

올라가지 않습니다. 이 사이트에는 업로드 기능 자체가 없습니다. 파일을 읽고 변환하는 일이 전부 브라우저 안에서 끝나기 때문에, 계약서나 사내 문서도 안심하고 열 수 있습니다. 인터넷을 끊어도 동작합니다.

Q.04

표나 코드, 체크리스트도 제대로 보이나요?

GitHub 스타일 표와 정렬, 체크박스, 각주, 접이식 블록, 코드 문법 강조를 지원합니다. 긴 문서에는 목차가 자동으로 생깁니다.

Q.05

md 파일을 PDF로 저장하거나 인쇄할 수 있나요?

문서를 연 상태에서 Ctrl+P 를 누르면 됩니다. 인쇄 전용 스타일이 따로 적용돼서 표나 코드 블록이 페이지 중간에서 잘리지 않습니다.

Q.06

마크다운을 한글이나 워드로 옮기려면?

문서를 연 뒤 서식 복사 버튼을 누르고 한글·워드·구글 문서에 붙여넣으면 제목, 굵은 글씨, 표, 표 안의 좌우 정렬, 목록이 그대로 살아 있습니다. ** 같은 기호가 딸려가지 않습니다. AI 가 써준 마크다운을 보고서에 넣을 때 쓰면 됩니다.

Q.07

탐색기에서 md 파일을 더블클릭해 열 수 있나요?
